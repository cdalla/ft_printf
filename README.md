<h1>PRINTF</h1>
The goal of this project is to reimplement printf(). This will teach primarily how to handle a variable number of arguments. <br>
This project gives the opportunity to explore and understand one of the most popular and versatile functions in C, <br> and to learn the concept of variadic functions. <br>
Allowed functions: malloc, free, write, va_start, va_arg, va_copy, va_end.
